Verify independently

The browser checks SHA-256 of query files it reads; it does not verify ML-DSA. Download the manifest, its signature and the pinned QRL release public key, then verify the manifest with qrlft:

qrlft verify -a mldsa --context=qrl-v1-testnet-archive-release-manifest --sigfile=manifest.json.sig --pkfile=theqrl-release-key.pub manifest.json

Check the key digest shown above. Each artefact signature in signatures.txt uses the separate qrl-v1-testnet-archive-release-signatures context. Verify every signed artefact against its manifest digest before trusting the complete release.

A point-in-time snapshot records testnet only through its stated cutoff. The public testnet can continue producing later blocks.
