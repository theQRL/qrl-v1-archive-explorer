Canonical block bytes

What you can reconstruct

This release contains the original serialized Block protobuf value for every testnet height from 0 through 1,620,000. The 163 .qrlblk files keep those values in order. Reassembling them gives an exact-byte block history; parsing and reserializing a protobuf would not necessarily preserve its original wire bytes.

The release is a snapshot of a testnet that is still running. Height 1,620,000 is this release's cutoff, not a terminal network block. The block files do not contain a ready-to-start QRL LevelDB database or independently reconstructed account state. The separately signed SQLite and query files include balances observed from two nodes at the cutoff; raw block shards alone do not reproduce those balances. See release status for the signed release and verification scope.

Format version 1

Read a shard

All integers below are unsigned and little-endian. There is no compression, padding, checksum trailer or split block. Byte lengths count bytes, not characters. A reader must reject short reads, unexpected trailing bytes, invalid lengths and a change in network or genesis identity.

Immediately after the header, repeat this record exactly record count times: uint64 height, uint64 protobuf_byte_length, then that many bytes of the stored QRL Block protobuf. The record height must match the protobuf header's block_number. The next record must have the next height, including across shard boundaries. Each complete shard is at most 67,108,864 bytes. The last shard has one record at height 1,620,000.

Keep the record's protobuf slice verbatim. A decoder is useful for validation and indexes, but its serialized output is not the preserved source value. Protobuf unknown fields and wire ordering can matter for exact-byte comparison.

Ordered inventory

Use shards.json as the map

shards.json has schema qrl.v1.archive.shards.v1 and format qrl-v1-block-stream-v1. Its shards array is already ordered; do not sort filenames or infer missing ranges. Each entry names a basename and gives first_height, last_height, record_count, bytes, sha256 and sha3_256. Both digests cover the entire shard, including header and record framing.

The top level pins network_id, genesis_hash, fork_height/fork_hash, terminal_height/terminal_hash, block and transaction counts, and configured shard caps. In this point-in-time release, the declared fork and terminal anchors are both height 1,620,000 with hash 8d7d8a30d928d52e74dd68f453d99604e5c8290c3df88d182353d4abcc8c0300. The protobuf source, generated binding and descriptor SHA-256 fields must match the files used by the structural verifier.

Pinned protobuf decoder

The release pins qrl.proto SHA-256 0d70a3372c4668a1bf4fd42983ae01f2e0fb54b4030b808bbea78e5adadb23f0, qrl_pb2.py SHA-256 a6d9fdd3d3490ae04171c4a6fd777bfc42ca2f38f73788893069cc366f7cd4d3 and its serialized descriptor SHA-256 9e65bd19e719a916f46ff2f3b9e5696996c2ae0203d0f9068e707395baf357f0. The archive source carries both files. Check all three pins before decoding.

Download and authenticate

Verify before extracting

  1. Get the release public key from the pinned security repository commit. Its file SHA-256 must be 8cf05c32a7cb69dfe27e5137b27baedf4ab0008a0684f36e59aa2553ff8f0c5f. Do not trust a key merely because the download succeeded.
  2. Download manifest.json and manifest.json.sig from this release prefix. Verify the manifest with qrlft and the separate manifest context shown below. The expected manifest SHA-256 for this release is b81739b982cdd4cd3082463598fac85b48e0fdf4fc887f1fea36dc40437a6e4b.
  3. Check the signed manifest's schema, product, tag and artifact context. Its artifact entries give basenames, sizes and SHA-256 digests. Download archive-inventory.json and shards.json; compare their exact bytes with the corresponding manifest entries. The inventory supplies the public object paths, SHA3-256 digests and whole block-stream digests. Compare every shard entry against both the index and inventory before using it.
  4. Download only safe basenames from the signed index. Check each shard's byte count, SHA-256 and SHA3-256. Then run the pinned structural verifier to check framing, protobuf header numbers and hashes, previous-hash links, transaction oneof presence, duplicate block and transaction hashes, and the genesis and cutoff anchors.

Download and hash-check the index and all 163 shards

Run this after the manifest signature command passes, from qrl-testnet-1620000/. It rejects unsafe paths, conflicting identities, duplicate names and digest mismatches. It never uses a directory listing from the data service.

from urllib.request import Request, urlopen
import hashlib, json, os, re

base = os.environ['RELEASE_BASE'].rstrip('/')
root = Path('payload')
manifest = json.loads(Path('manifest.json').read_bytes())
def need(condition, message):
    if not condition:
        raise ValueError(message)

need(manifest['schema'] == 'theqrl.release-manifest.v1', 'manifest schema')
need(manifest['product'] == 'qrl-v1-testnet-archive', 'manifest product')
need(manifest['tag'] == 'testnet-snapshot-h1620000-8d7d8a30-r1', 'manifest tag')
need(manifest['context'] == 'qrl-v1-testnet-archive-release-signatures', 'manifest context')
need(root.is_dir() and not root.is_symlink(), 'payload directory must be real')
artifacts = {a['filename']: a for a in manifest['artifacts']}
need(len(artifacts) == len(manifest['artifacts']), 'duplicate manifest filename')

def digest(data, kind):
    return hashlib.new(kind, data).hexdigest()

def fetch(name, size, sha256, sha3=None):
    need(bool(re.fullmatch(r'[A-Za-z0-9][A-Za-z0-9._-]*', name)), 'unsafe filename')
    need(name not in ('.', '..') and 0 < size <= 67108864, 'invalid size or filename')
    path = root / name
    need(not path.is_symlink(), 'symlink is not a release file: ' + name)
    if path.exists():
        data = path.read_bytes()
    else:
        request = Request(base + '/' + name, headers={'User-Agent': 'Mozilla/5.0'})
        with urlopen(request, timeout=120) as response:
            data = response.read(size + 1)
    need(len(data) == size and digest(data, 'sha256') == sha256, 'size or SHA-256: ' + name)
    if sha3 is not None:
        need(digest(data, 'sha3_256') == sha3, 'SHA3-256: ' + name)
    if not path.exists():
        with path.open('xb') as destination:
            destination.write(data)
    return data

def signed_file(name):
    item = artifacts[name]
    return fetch(name, item['size'], item['sha256'])

index = json.loads(signed_file('shards.json'))

need(inventory['tag'] == manifest['tag'], 'inventory tag')
need(inventory['object_prefix'] == 'testnet/snapshots/' + manifest['tag'], 'object prefix')

need(snapshot['network_id'] == index['network_id'] == 'testnet', 'network ID')
need(snapshot['genesis_hash'] == index['genesis_hash'] == 'd6765d6e0af7e8b25bac587279999e16bbb0bd3038445934e2d9f3b24a89041e', 'genesis hash')
need(snapshot['height'] == index['terminal_height'] == index['fork_height'] == 1620000, 'cutoff height')
need(snapshot['hash'] == index['terminal_hash'] == index['fork_hash'] == '8d7d8a30d928d52e74dd68f453d99604e5c8290c3df88d182353d4abcc8c0300', 'cutoff hash')
need(index['schema'] == 'qrl.v1.archive.shards.v1', 'shard index schema')
need(index['block_stream_format'] == 'qrl-v1-block-stream-v1', 'block stream format')
need(snapshot['block_count'] == index['block_count'] == 1620001, 'block count')
need(snapshot['transaction_count'] == index['transaction_count'] == 1621730, 'transaction count')
need(len(index['shards']) == 163, 'shard count')
objects = {p['filename']: p for p in inventory['payloads']}

for name in ('shards.json',):

    data = (root / name).read_bytes()
    need(item['role'] == 'canonical_shard_index' and item['object_path'] == name, 'index mapping')
    need(item['size'] == len(data) and item['sha256'] == digest(data, 'sha256'), 'index SHA-256')
    need(item['sha3_256'] == digest(data, 'sha3_256'), 'index SHA3-256')

next_height = 0

Exact-byte extraction

Rebuild one ordered block stream

Run this after the signed download and structural check pass. It writes blocks-framed.bin as the ASCII domain marker qrl-v1-canonical-block-bytes-v1 plus one NUL byte, followed by each block's uint64 height, uint64 byte length and exact original protobuf bytes. The marker and frames are the whole-stream digest input recorded in the signed inventory. The expected SHA-256 is 5d8437458b44ee6fac10838a169a1ffd943f7da912eabdb5c04f33256613eed5; SHA3-256 is 72c9c5ea9b8a8467806fad16b0694561ed6d1f8128d459af7f5796c44b62f8cd. These values check the byte stream after you authenticate the manifest. The file is an archive transport stream, not a QRL node database.

Runnable Python 3 extraction

Run from qrl-testnet-1620000/. This uses only the Python standard library, checks file bounds and digests again, refuses an existing output, and removes a partial output on failure. It checks both final whole-stream hashes against the manifest-authenticated inventory.

python3 - <<'PY'
from pathlib import Path
import hashlib, io, json, re, struct

root = Path('payload')
if not root.is_dir() or root.is_symlink():
    raise ValueError('payload directory must be real')
index = json.loads((root / 'shards.json').read_bytes())
inventory = json.loads((root / 'archive-inventory.json').read_bytes())
expected = inventory['snapshot']
domain = b'qrl-v1-canonical-block-bytes-v1\x00'
out = Path('blocks-framed.bin')
if out.exists():
    raise FileExistsError(out)
sha256, sha3 = hashlib.sha256(), hashlib.sha3_256()
next_height = 0

def read_exact(stream, size):
    data = stream.read(size)
    if len(data) != size:
        raise ValueError('truncated shard')
    return data

def u32(stream):
    return struct.unpack('<I', read_exact(stream, 4))[0]

def u64(stream):
    return struct.unpack('<Q', read_exact(stream, 8))[0]

def emit(destination, data):
    destination.write(data)
    sha256.update(data)
    sha3.update(data)

try:
    with out.open('xb') as destination:
        emit(destination, domain)
        for shard in index['shards']:
            name = shard['name']
            if not re.fullmatch(r'[A-Za-z0-9][A-Za-z0-9._-]*', name) or name in ('.', '..'):
                raise ValueError('unsafe shard filename')
            path = root / name
            if path.is_symlink():
                raise ValueError('symlink shard: ' + name)
            data = path.read_bytes()
            if not (len(data) == shard['bytes'] <= 67108864):
                raise ValueError('shard size mismatch: ' + shard['name'])
            if hashlib.sha256(data).hexdigest() != shard['sha256']:
                raise ValueError('SHA-256 mismatch: ' + shard['name'])
            if hashlib.sha3_256(data).hexdigest() != shard['sha3_256']:
                raise ValueError('SHA3-256 mismatch: ' + shard['name'])
            stream = io.BytesIO(data)
            if read_exact(stream, 8) != b'QRLV1BLK' or u32(stream) != 1:
                raise ValueError('unsupported shard: ' + shard['name'])
            network_length = u32(stream)
            if not 1 <= network_length <= 128:
                raise ValueError('bad network length')
            network = read_exact(stream, network_length).decode('utf-8')
            genesis_length = u32(stream)
            if genesis_length != 32:
                raise ValueError('bad genesis length')
            genesis = read_exact(stream, 32).hex()
            first, last, count = u64(stream), u64(stream), u64(stream)
            if network != index['network_id'] or genesis != index['genesis_hash']:
                raise ValueError('shard chain identity mismatch')
            if (first, last, count) != (shard['first_height'], shard['last_height'], shard['record_count']):
                raise ValueError('shard index mismatch')
            if first != next_height or not 1 <= count <= 10000 or last != first + count - 1:
                raise ValueError('gap or overlap in heights')
            for _ in range(count):
                height, length = u64(stream), u64(stream)
                if height != next_height or not 1 <= length <= len(data) - stream.tell():
                    raise ValueError('bad block record')
                raw_block = read_exact(stream, length)
                emit(destination, struct.pack('<QQ', height, length))
                emit(destination, raw_block)
                next_height += 1
            if stream.read(1):
                raise ValueError('trailing shard bytes')
        if next_height != index['block_count'] or next_height != expected['block_count']:
            raise ValueError('incorrect final height')
        if sha256.hexdigest() != expected['block_stream_sha256']:
            raise ValueError('whole-stream SHA-256 mismatch')
        if sha3.hexdigest() != expected['block_stream_sha3_256']:
            raise ValueError('whole-stream SHA3-256 mismatch')
except BaseException:
    out.unlink(missing_ok=True)
    raise
print('PASS:', next_height, 'original block values; stream SHA-256', sha256.hexdigest())
PY

To extract block n from the resulting file, skip the domain marker, then read successive <QQ> height and length pairs. The next length bytes are that block's exact stored protobuf value. Reject a skipped, repeated or out-of-range height. Decode with the pinned qrl_pb2.Block only after preserving the raw slice. Do not reconstruct original bytes with SerializeToString().

What further recovery would require

The structural reader provides verified records and exact byte offsets. The derive-sqlite command rebuilds block, transaction and address-event tables, but currently reports INCOMPLETE with exit code 4. It does not replay all historical consensus and state rules or reproduce the observed final-address-state table. Use the separately signed snapshot SQLite and query files for the explorer's cutoff balances. A running QRL node requires a separate, tested restore or replay path that produces compatible LevelDB state and proves the expected tip. The canonical shards remain usable as an offline historical record without that path.
