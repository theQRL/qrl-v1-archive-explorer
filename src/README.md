# Explorer source

The static Pages site is served from `public/`. `build-pages.mjs` generates the testnet block, transaction, address and release pages and copies the browser modules into `public/assets/`. Search controls stay disabled while `/testnet/snapshot-config.json` is absent or fails its release checks.

`build-query-packs.py` derives bounded, deterministic lookup files from a certified read-only SQLite snapshot. It refuses an existing output directory and writes to a new `.partial` directory. `query-packs-index.json` binds the files to the network, genesis, cutoff height/hash, canonical stream SHA-256 and source SQLite SHA-256, and lists each file's byte length, SHA-256 and SHA3-256. `verify-query-packs.py` rehashes every file and compares blocks, hash indexes, address events and observed account states with the SQLite source. A passing pack check remains unsigned private evidence until the full release passes signing and served-byte verification.

`snapshot-query.mjs` fetches only immutable query files from the archive data domain. The activation receipt binds the operator's independent signature check, public served-byte check, signed manifest, manifest signature and query index to one release ID and cutoff. The two verification reports are same-origin Pages files under `/testnet/reports/<release-id>/`; the signed data Worker serves only release objects. If any check or file fails, the browser leaves lookups disabled and shows a failure notice. The browser checks SHA-256 for every complete query pack and exact address-history Range page it uses; it does not itself perform ML-DSA signature verification. Readers can obtain the signed manifest and signature from the release page and verify them with the independent QRL tool. The current activation file was added after the public download and operator review passed.

Block and transaction hashes use binary search in small first-byte hash buckets. Blocks and all transaction outputs live in 1,000-height JSON packs. Each address has an index entry pointing to fixed-size event records; a 25-row history page uses one exact HTTP Range request. A balance appears only when the signed snapshot includes independently matched stopped-node state at the cutoff, labelled as observed state rather than consensus replay.
